#Personal Website
A personal website built as a space to write about things I find interesting, share my thoughts, and create something of my own. The site is based on the Cactus Astro theme created by Chris Williams, which I customized and adapted to create my own personal website.

#Why I built it
I had always wanted to have a website of my own, a space where I could write about things I find interesting and share my thoughts. At the same time, I wanted to understand how a website actually works rather than simply using a website builder.
This project gave me an opportunity to work with an existing Astro theme, customize it, and learn how to use the terminal, Git, and GitHub. Through the process, I also developed a better understanding of what GitHub is, how a project is managed through a repository, and how changes to a website can be tracked and pushed online.
